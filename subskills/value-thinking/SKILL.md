# 价值主义思维

## 核心思想

- **价格 ≠ 价值**：价格是市场此刻的标签，价值是事物长期能产生的效用/现金流/意义。短期看投票机，长期看称重机（格雷厄姆）。
- **价值锚**：每个判断都需要一个锚——替代品成本、历史中枢、现金流折现、重置成本。没有锚的"值不值"全是感觉。
- **安全边际**：估值必然有误差，只在价格显著低于价值时出手，为错误和坏运气留出缓冲。
- **能力圈内估值**：看不懂的东西无法估值，无法估值的东西再便宜也不碰。
- **时间的价值折现**：同样的收益，早拿到比晚拿到值钱；同样的成本，晚付比早付划算。

## 分析步骤

1. 定义价值对象：要估值的东西是什么（商品、工作机会、公司、一段关系、一项技能）？
2. 找价值锚：它的内在价值用什么衡量——替代成本、产生现金流的能力、长期效用、重置成本？
3. 估内在价值区间：给出保守-中性-乐观三档估值，而不是一个精确数字。
4. 对比价格：当前要付出的价格落在估值区间的什么位置？
5. 算安全边际：价格比保守估值低多少？缓冲够吗？
6. 检验能力圈：这个估值依赖的假设我真的懂吗？还是在听别人报价？

## 关键问题清单

- 抛开价格标签，这东西本身能为我创造什么？
- 如果市场上没人给它报价，我愿意为它付多少？
- 我的估值锚是什么？换成另一个锚，结论会翻转吗？
- 价格低于价值，是市场错了还是我错了？我知道市场不知道什么？
- 这个"便宜"是价值回归的机会，还是价值毁灭的开始？（价值陷阱检验）
- 如果价格再跌 50%，我是高兴（加仓）还是恐慌（怀疑人生）？

## 输出要求

- 限长：默认模式 ≤300 字，全部模式 ≤150 字。
- 核心判断：一句话给出 价格 vs 价值 的关系判断（低估/合理/高估/无法估值）。
- 分析：价值锚 → 估值区间 → 安全边际 → 价值陷阱检验。
- 行动含义：给出 买入/持有/放弃/等待 的建议及触发价格或条件。

## 何时不适用

- 价值高度主观、无共同锚点的纯偏好问题（艺术品收藏只为喜欢）。
- 时效性强于估值重要的场景（救命的东西不看价格）。
- 非交易性问题，价值框架沦为生搬硬套。
- 与经济学思维的分工：经济学思维管**成本结构与配置效率**（机会成本、边际、比较优势）；本模型管**价格与内在价值的差额**（估值、安全边际）；判据是「做 A 还是 B 谁划算」还是「贵不贵、该不该买」。

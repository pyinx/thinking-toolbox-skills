# 基准率、驱动力与可证伪预测

预测的五环链条：**基准率 → 驱动力 → 反作用力 → 拐点信号 → 证伪条件**。
漏掉任一环，预测就只是感想。

> 阅读本文件后，回答中**必须出现**：①基准率数值及其来源年份 ②驱动力与反作用力的配对
> ③至少一个拐点信号 ④证伪条件。缺任一项视为未按本文件作答。

---

## 一、基准率（外部视角优先）

### 为什么先看基准率

人天生从"内部视角"评估：我了解这件事、这是我特殊的情况，所以概率更高。
但**外部视角**（这类事情历史上通常怎样）才是更好的起点。

### 基准率类型

| 类型 | 示例 | 获取方式 |
| --- | --- | --- |
| 频率基准率 |  startups 中 X% 活过 5 年 | 行业统计、公开数据库 |
| 人口基准率 | 同年龄组婚姻持续年限分布 | 人口统计公报 |
| 项目基准率 | 同类项目延期率 | 历史项目复盘 |
| 生理基准率 | 疾病自然病程 | 医学文献 |
| 市场基准率 | 新品类渗透速度曲线 | 行业报告（**必须记年份**） |

### 纪律

- **数值必须带来源与年份**。没有来源的基准率数字 = 编数字，比不给更糟。
- 找不到精确基准率时，用量级估计并标注"量级估计，未找到统计源"。

---

## 二、驱动力与反作用力配对

任何趋势都有推动它的力量和对抗它的力量。**预测 = 判断两股力量的相对强弱与反转时点。**

### 驱动力（推动趋势继续）

逐条列出，可量化：
- 政策支持 / 补贴 / 税收优惠
- 技术成本下降曲线
- 用户渗透率曲线
- 资本投入规模
- 网络效应的自我强化

### 反作用力（对抗趋势）

同样逐条列出：
- 补贴退坡后的付费意愿断层
- 技术瓶颈 / 落地成本
- 监管收紧
- 替代方案出现
- 边际用户成本收益为负

### 配对分析

对每条驱动力，找它对应的反作用力，并问：

1. **当前哪一方更强？**（用可观测指标判断，不靠感觉）
2. **哪一方会先耗尽？**（决定拐点方向）
3. **有什么迹象表明力量对比已反转？**（→ 拐点信号）

> 只列驱动力不列反作用力，是最常见的乐观偏见来源。

---

## 三、拐点信号（事前写下）

**拐点信号 = 趋势反转的可观测指标**。必须在预测时就写好，事后再找永远能找到"解释"。

### 好的拐点信号特征

- **可观测**：有公开数据或明确事件
- **领先**：在趋势反转前 3~12 个月出现
- **无歧义**：不会既可解释为"反转"又可解释为"噪声"

### 常见拐点信号类型

| 类型 | 示例 |
| --- | --- |
| 供给侧 | 产能开工率跌破阈值、核心人才大规模流出 |
| 需求侧 | 复购率连续两季下滑、新客获取成本翻倍 |
| 价格侧 | 补贴退坡后付费率断崖 |
| 政策侧 | 监管文件出台、补贴规则变更 |
| 技术侧 | 关键性能瓶颈被突破或长期停滞 |
| 情绪侧 | 从"人人看好"转向"无人问津"（反向指标） |

## 四、证伪条件（预测的必备件）

**没有证伪条件的预测不是预测，是立场。**

### 写法

```
若在 <时间窗口> 内出现 <可观测信号>，则本预测被证伪。
```

### 示例

- "若 2027 年 Q3 前企业级付费客户数未突破 <X> 家，则'三年内跑通商业模式'的判断被证伪。"
- "若政策补贴在 2026 年底前完全退坡而付费率未回升，则需求真实性的判断被证伪。"

### 纪律

1. **时间窗口必须明确**，不能写"如果长期来看不行"
2. **信号必须可观测**，不能写"如果市场不接受"
3. **证伪条件要在预测时就写**，事后补的证伪条件会自动被写成"怎么算都对"

## 五、五环自检

写完预测后逐项核对：

```
□ 基准率是多少？来源与年份？
□ 驱动力列了几条？各有什么可观测指标？
□ 反作用力列了几条？它对应的驱动力是哪条？
□ 哪一方会先耗尽？依据是什么？
□ 拐点信号是什么？何时可观测到？
□ 证伪条件是什么？时间窗口到什么时候？
□ 置信度（高/中/低）与理由？
```

任一项答不上来 → 该预测不可用，先补齐。

---

## 六、不做多轮追问式调研

本文件只解决「事实是否存在、是否过期、方向如何」。
**不做**为了一次预测去展开深度调研——那是趋势推演的边界，超出即属于另一个模型（预测思维自己的职责）与另一步骤（联网取证）的范围。

预测的价值在于**方向与量级**，不在精确点位。追求精确点位是预测失败的开始。

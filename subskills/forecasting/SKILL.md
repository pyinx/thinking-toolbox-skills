# 预测思维

## 核心思想

- **基准率优先**：先看这类事情历史上发生的概率（外部视角），再根据个人情况微调（内部视角）。人天然反过来做，这是预测偏差的最大来源。
- **驱动力与反作用力**：任何趋势都有推动它的力量和对抗它的力量；预测=判断两股力量的相对强弱何时反转。
- **概率表达**：不说"会/不会"，说"70% 概率在 2 年内发生"。可校准的预测必须可证伪。
- **拐点信号**：事前写下"如果 X 发生就说明趋势反转"，比实时解读新闻可靠得多。
- **超级预测者的习惯**（泰特洛克）：频繁小幅更新、分解问题、综合多源信息、对确定性保持警惕。

## 分析步骤

1. 把预测问题写成可证伪形式：什么事件、在什么时间范围内、以什么可观测标准判定？
2. 查基准率：同类事件的历史发生频率是多少？
3. 列驱动力：哪些结构性力量在推动它发生？
4. 列反作用力：哪些力量在阻止或延缓它？
5. 定概率：综合给出概率估计和时间窗口，写明推理依据。
6. 写证伪条件：出现什么信号就承认自己错了？什么信号则加仓这个判断？

## 关键问题清单

- 这类事情上一次发生是什么时候？之前发生过几次？
- 如果我只能知道一个统计数字来预测它，我要哪个？
- 什么新闻出现时，说明我低估了它？什么说明我高估了？
- 我的预测里有多少是"希望它发生"的成分？
- 如果给这个预测下注真金白银，我还敢报同样的概率吗？
- 半年/一年后用什么指标检验我今天的判断？

## 输出要求

- 限长：默认模式 ≤300 字，全部模式 ≤150 字。
- 核心判断：概率化表述的预测（含时间窗口），如"60% 概率在 18 个月内……"。
- 分析：基准率 → 驱动力 → 反作用力 → 概率推导。
- 行动含义：给出按此预测应做的准备，以及需要盯住的拐点信号清单。

## 何时不适用

- 结果已经确定、只差揭晓的问题。
- 极端黑天鹅事件，无基准率可参考（此时改用情景规划）。
- 纯随机事件（掷硬币），预测无意义。
- 与概率思维的分工：概率思维管**新证据到手后如何更新已有信念**（似然比、基准率校正）；本模型管**无新证据时如何从基准率与趋势生成预测**；判据是「明年会不会发生、凭什么」还是「这份数据改变了什么」。

# 持久战三阶段

出处：《论持久战》（1938）。本文件提供三阶段的进入/退出判据、速胜论与亡国论的识别、集中兵力的分配原则。

> 阅读本文件后，回答中**必须出现**：①当前处于哪个阶段 ②该阶段的进入判据是否满足 ③退出条件是什么。

---

## 一、三阶段与判据

持久战的前提是**敌强我弱**（或至少力量对比不明）。三阶段各有进入与退出条件。

### 阶段一：战略防御

| 项 | 内容 |
| --- | --- |
| **目标** | 保存自己，消耗对方 |
| **进入判据** | 力量对比明显不利（对方可集中兵力，你不能） |
| **典型动作** | 退守、缩短战线、保存实力、避开锋芒 |
| **风险** | 退得太久会耗尽内部；退得太急会损失人心 |
| **退出判据** | ①己方力量开始积累（每战有得失账）②对方出现可攻击的集中点 |

### 阶段二：战略相持

| 项 | 内容 |
| --- | --- |
| **目标** | 力量对比胶着，双方都在消耗；寻找转机 |
| **进入判据** | 你已稳住阵脚，对方无法速胜 |
| **典型动作** | 局部主动出击、保存自己的同时改变局部对比、扩大同盟、等待时机 |
| **风险** | **速胜论的温床**——"再打几场就差不多了"是最常见的幻觉 |
| **退出判据** | ①己方力量对比开始改善 ②出现可被攻击的敌方薄弱点 |

### 阶段三：战略反攻

| 项 | 内容 |
| --- | --- |
| **目标** | 在有利条件下决战，收复失地 |
| **进入判据** | **力量对比已改变**（不是感觉好，是确实变了） |
| **典型动作** | 集中优势兵力打歼灭战、逐个击破 |
| **风险** | 进入太早 → 速胜论的陷阱；进入太晚 → 错过窗口 |
| **退出** | 不适用（胜利或失败） |

---

## 二、阶段判断的三问

1. **力量对比**：客观对比对方可集中的兵力与我方可用资源（不是估算，是数字）
2. **趋势方向**：对比是在改善、持平、还是恶化？（恶化则回相持）
3. **出现弱点**：对方是否出现可攻击的集中点？（这是从相持到反攻的**唯一门槛**）

**三问中第 3 问不成立，就不要进反攻。** "感觉差不多了"不是判据。

## 三、速胜论与亡国论

《论持久战》批判的两种错误，做长期判断时必须自检：

| 错误 | 心理根源 | 语言特征 | 纠正 |
| --- | --- | --- | --- |
| **速胜论** | 期待捷径、厌恶长期消耗 | "再坚持一下就胜利了""集中力量就能拿下" | 承认力量对比需要时间改变，列出积累项与所需时间 |
| **亡国论** | 对长期消耗的疲惫、看不到积累的希望 | "反正坚持也没用""拖下去只会更糟" | 承认对比会变，找出那个能积累的变量 |

**自检方法**：把自己对未来的判断写成两段——"如果我方力量持续改善"与"如果对方力量持续加强"，
看自己偏向哪一段、偏得有多厉害。偏得厉害说明有速胜论或亡国论在起作用。

## 四、集中优势兵力的分配原则

出自《中国革命战争的战略问题》。

### 原则

- **集中优势兵力，各个歼灭敌人**：在决定性的地点、决定性的时机，用压倒性力量
- **力戒平均主义**：击溃十个不如歼灭一个；平均分配兵力等于零效果
- **打歼灭战而非运动战**：运动战是"到处打"，歼灭战是"集中打一处"

### 警戒线：集中 ≠ 孤注一掷

| 做法 | 判断 |
| --- | --- |
| 在关键点投入超过其他任何点的兵力，但留有预备队 | **正确的集中** |
| 全部兵力押在一处，无任何后备 | **孤注一掷**（毛选明确反对） |
| 十个方向各投一点资源 | **平均主义**（明确反对） |

**为什么留预备队**：歼灭敌人需要打**两遍**——第一遍消耗其有生力量，
第二遍才能彻底接管。集中是为了第二遍能多点兵力，不是为了第一遍好看。

## 五、持久战与 guerrilla 的关系

- **持久战**：战略层面的总路线，决定"要打多久、为什么能赢"
- **游击战**：战术层面的具体方式，"敌进我退、敌驻我扰、敌疲我打、敌退我追"

**持久战需要游击战的具体动作来填充**——战略正确但战术无从落地，等于没有持久战。
做长期判断时，两层都要给：长期怎么耗赢（战略）、短期内每一步怎么走（战术）。

# 《矛盾论》方法：主要矛盾与矛盾的主要方面

出处：《毛泽东选集》第一卷《矛盾论》（1937）。
本文件提供两段判定程序、错误用法纠正、矛盾清单模板。

> 阅读本文件后，回答中**必须出现**：①判定出的主要矛盾 ②该矛盾的主要方面是什么
> ③据此确定的工作中心。不能只说"要抓主要矛盾"而不给出是哪一个。

---

## 一、两段判定程序

### 第一段：选主要矛盾（抓工作中心）

**输入**：局面中所有矛盾。
**输出**：唯一一个"主要矛盾"——它规定和影响着其他矛盾。

四步：

1. **罗列矛盾**：穷尽列出，不遗漏（清单模板见下节）
2. **逐个问"解决它能带动几个"**：能带动最多其他矛盾的那个 = 主要矛盾
3. **验证是否长期存在**：只出现一次的矛盾不是主要矛盾（那只是偶然因素）
4. **验证是否规定其他矛盾**：若它消解后其他矛盾自动缓解 → 确认

> 判据口诀：**"牵牛要牵牛鼻子"**——主要矛盾就是那个牛鼻子。

### 第二段：定矛盾的主要方面（定性质）

同一个矛盾内部，必有一方占主导地位，它决定事物的性质。

**四步**：

1. **摆出矛盾双方**：A 与 B 分别是什么
2. **问哪个是主导**：A 压倒 B，还是 B 压倒 A
3. **判断是否会转化**：什么条件下 A 会变成 B（量变到质变）
4. **据此定对策**：抓主导方面，同时盯住转化的条件

> 关键提醒：**矛盾的主要方面会转化**。今日的强势方可能因条件变化变成弱势方。
> 任何"永远甲方强势/永远乙方强势"的判断都是静态的、危险的。

## 二、错误用法纠正

| 错误用法 | 后果 | 正确做法 |
| --- | --- | --- |
| 把"主要矛盾"理解为"最主要的问题" | 变成了挑最难的事，而非最该先做的事 | 主要矛盾 = 解决它能带动最多的那个 |
| 把所有矛盾并列，不分主次 | 平均用力，什么都推不动 | 列出矛盾只是为了**找到**主要矛盾，不是接受并列 |
| 只抓主要矛盾，不看转化条件 | 局面变化后仍死抓原来的矛盾 | 每条判定都附"转化条件" |
| 把矛盾主要方面当成不变的属性 | 误判形势（"我方一向更强"） | 每次判断都要重新看当前谁占主导 |

## 三、矛盾清单模板

分析任何局面，至少过一遍这六类矛盾：

| 类别 | 典型对立 |
| --- | --- |
| **敌我** | 我方 vs 对方；盟友 vs 对手 |
| **供需** | 供给能力 vs 需求；产能 vs 市场容量 |
| **快慢** | 立刻见效 vs 需要时间；短线收益 vs 长线价值 |
| **质与量** | 积累的量变 vs 临界点后的质变 |
| **理想与现实** | 应有的状态 vs 实际的状态 |
| **局部与全局** | 部门最优 vs 整体最优 |

### 填写格式

```
1. <矛盾 A> vs <矛盾 B> —— 解决它能带动 <N> 个其他矛盾？ 持续存在？ 是/否
2. ...
```

填完直接看哪一条的"能带动 N"最大、且"持续存在"为是——那条就是主要矛盾。

## 四、集中力量

确认主要矛盾后，**所有资源集中于此**——这是毛选方法论的落脚点。

- **力戒平均主义**：击溃十个对手不如歼灭一个，分散投入等于零
- **集中优势兵力打歼灭战**：在决定性的地点、决定性的时机，用压倒性力量
- **集中不等于孤注**：集中的是**优势兵力**，不是全部身家。留预备队

**警戒线**：把"集中"做成"孤注一掷"是误用。正确的集中是——
在这个点上投入的兵力，**必须超过其他任何点**，但同时留有可调动的余量。

## 五、速胜论与亡国论

《论持久战》中的两个典型错误（做持久判断时必须自检）：

| 错误 | 特征 | 纠正 |
| --- | --- | --- |
| **速胜论** | 估短的乐观——"很快就能拿下" | 看清楚敌强我弱的现实基本盘，找可积累的优势 |
| **亡国论** | 估长的悲观——"反正没戏" | 忽略矛盾双方力量对比会变化的可能 |

**正确姿势**：承认敌强我弱的现实，同时相信力量对比会随时间变化——
找出那个能积累、能在未来改变对比的变量，围着它打持久战。

## 六、调查研究（前置条件）

《反对本本主义》原文："**一切结论产生于调查情况的末尾，而不是在它的先头。**"

**先调查再定矛盾**。未经调查的矛盾清单，往往是凭想象的——那么后面的"主要矛盾"分析全建立在沙上。

调查顺序（详见 `investigation-protocol.md`）：事实 / 听说 / 想象 三分法 → 标注哪些未查证 → 先补调查再定矛盾。

# 辩证思维

## 核心思想

- **对立统一**：任何事物都包含相互对立的两个方面，它们互相依存、互为条件——没有绝对的优点或缺点，只有在特定条件下成立的性质。
- **矛盾的转化**：祸兮福所倚，福兮祸所伏。优势用过头变成包袱，弱项逼出替代路径变成特色。条件一变，攻守易形。
- **质量互变**：量变积累到一定程度引发质变。渐变期看起来什么都没发生，质变点突然到来。要识别当前处在积累期还是临界区。
- **否定之否定**：发展不是直线而是螺旋——正题→反题→合题。新的阶段看似回到原点，实则站在更高层次。
- **度的把握**：真理多走一步成谬误。关键不是"要不要"，而是"到什么程度"——过犹不及。

## 分析步骤

1. 找对立面：这个问题里相互矛盾的两极是什么？（扩张vs收缩、快vs慢、集权vs放权）
2. 分析依存关系：两极如何互为条件？失去一方，另一方还成立吗？
3. 判断主导方面：当前条件下，矛盾的哪一方占主导？它决定了事物的性质。
4. 推演转化条件：什么条件出现时，主导方面会向对立面转化？
5. 定位量变质变：现在处于量变积累期还是质变临界区？该耐心积累还是主动引爆？
6. 校准"度"：当前的做法过了还是不及？合适的刻度在哪？

## 关键问题清单

- 这个优点，在什么条件下会变成缺点？
- 我极力避免的坏处里，藏着什么好处？
- 对立的两面，各在什么条件下成立？我能在不同阶段用不同面吗？
- 现在的"稳"，是不是正在积累将来的"变"？
- 从正题到反题之后，更高层次的合题长什么样？
- 这件事的"度"在哪里——多少算够，多少算过？

## 输出要求

- 限长：默认模式 ≤300 字，全部模式 ≤150 字。
- 核心判断：一句话指出问题中的主要矛盾及其当前主导方面。
- 分析：对立面 → 依存关系 → 转化条件 → 量变质变定位 → 度的校准。
- 行动含义：给出分阶段、有条件的行动建议（"在什么条件下做 A，条件变化后转做 B"）。

## 何时不适用

- 有标准答案的技术/事实问题，无需辩证权衡。
- 需要明确立场快速决断的场合，辩证易沦为"两面都说等于没说"。
- 原则性底线问题，不适用"度"的弹性。

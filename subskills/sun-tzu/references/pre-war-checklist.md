# 起兵前算战 Checklist

20 项是/否判断题，分五组（对应孙子五事）。**veto 项任一为否，即判定此仗不可打**。

用法：逐项回答"是/否/不确定"。veto 项全为是才继续；否则直接转"走为上"。

---

## 道（人心与共识）— veto 2 项

| # | 检查项 | veto |
| --- | --- | --- |
| 1 | 核心成员是否都清楚为什么要做这件事 | |
| 2 | 关键执行者是否认同目标（而非只服从命令） | ★ |
| 3 | 上面的目标与下面想要的东西是否一致 | |
| 4 | 事后论功行劳的分配规则是否已说清 | |

## 天（时机）— veto 1 项

| # | 检查项 | veto |
| --- | --- | --- |
| 5 | 是否踩在窗口期（不是早半步或早五步） | ★ |
| 6 | 有没有不可控的外部变量正在逼近 | |
| 7 | 天气/季节/时令是否反着来 | |

## 地（资源与空间）— veto 1 项

| # | 检查项 | veto |
| --- | --- | --- |
| 8 | 资源够支撑多久（现金流/弹药/人力能撑几个月） | ★ |
| 9 | 补给线是否安全，或有备选路线 | |
| 10 | 地形是否对我方不利 | |

## 将（主帅与授权）— veto 1 项

| # | 检查项 | veto |
| --- | --- | --- |
| 11 | 决策者是否能承责（而非集体背锅） | ★ |
| 12 | 指挥链是否清晰，不出现多头指挥 | |
| 13 | 是否有人有权限在紧急时止损 | |

## 法（组织与纪律）— veto 1 项

| # | 检查项 | veto |
| --- | --- | --- |
| 14 | 赏罚是否明确到人（而非"表现好的奖励"） | ★ |
| 15 | 退出机制是否真的可用（想撤能撤吗） | |
| 16 | 失败后的问责方式事先说清了吗 | |

## 势（动能与士气）— 非 veto，但影响胜算

| # | 检查项 |
| --- | --- |
| 17 | 现在是主动进攻还是被动应对 |
| 18 | 团队士气在上升还是下滑 |
| 19 | 有没有可借的外势（第三方支持、行业时机） |

## 算（情报与计算）— 非 veto

| # | 检查项 |
| --- | --- |
| 20 | 是否掌握了对方的关键底牌，还是在猜 |

---

## 判读

- **veto 有"否"** → 此仗不可打。转"走为上"：保存实力，明确撤退条件。
- **veto 全"是"但第 20 项为"否"** → 情报不足。可以打，但先补情报，别用猜测上战场。
- **veto 全"是"且第 20 项为"是"** → 可以打。仍须写下：停战条件是什么。

## 停战条件（开打前必须写）

开打前写下三件事，中途任何一条成立即考虑停战：

1. **时间止损**：到 X 月 Y 日仍未取得进展 → 停
2. **资源止损**：消耗超过 Z（金额/人力/时间）→ 停
3. **局面止损**：出现某信号（如己方核心人员动摇、对方获得不可解的外援）→ 停

> 停战条件写在开打**之前**，而不是打到一半才想——这是孙子"胜兵先胜而后求战"在时间轴上的应用。

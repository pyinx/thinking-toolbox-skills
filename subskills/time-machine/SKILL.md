# 时光机思维

## 核心思想

- **时光机理论**（孙正义）：事物在不同市场的发展有先后——在美国发生的，几年后会在中国发生，再几年后在印度等新兴市场发生。坐上时光机，去未来看一眼再回来布局。
- **阶段映射**：新事物在本地的位置，对应成熟市场的哪个年份？那个年份之后发生了什么？
- **跨时空套利**：信息差、认知差、模式差都是可套利的——把 A 地验证过的东西搬到 B 地，比原创风险低得多。
- **适用前提检验**：时光机不是万能的——基础设施、人口结构、监管、文化相似性决定映射是否成立。映射失败常因前提不同。
- **节奏比方向重要**：看得对但来得太早 = 先烈。判断本地市场到了哪个阶段，决定是进场还是等待。

## 分析步骤

1. 定位参照系：这个问题/事物在更成熟的市场（或更先发的领域）是什么样子？
2. 标定时间坐标：本地当前状态 ≈ 成熟市场的哪一年？
3. 回放"未来"：参照市场在那个时点之后，经历了哪些阶段、死过哪些玩家、谁赢了为什么？
4. 检验映射前提：基础设施/用户习惯/监管/支付能力等前提条件，本地与参照地相同吗？
5. 推导行动：基于"已知的未来"，现在该布局什么、避开什么、等什么？
6. 设定验证点：哪些信号出现，说明本地正在复刻参照路径（或已经偏离）？

## 关键问题清单

- 这件事在更成熟的市场已经演化到哪一步了？
- 本地市场相当于参照市场的哪一年？依据是什么？
- 参照市场在这个阶段的赢家做对了什么？炮灰死在哪？
- 本地和参照地最大的不同是什么？这个不同会颠覆映射吗？
- 我是早半步（先锋）还是早五步（先烈）？
- 哪些"未来必然发生的事"，本地还没人认真准备？

## 输出要求

- 限长：默认模式 ≤300 字，全部模式 ≤150 字。
- 核心判断：一句话给出跨时空映射结论——本地处于什么阶段、"未来"会发生什么。
- 分析：参照系 → 时间坐标 → 未来回放 → 前提检验。
- 行动含义：给出基于时间差的布局建议与需要盯住的验证信号。

## 何时不适用

- 真正全新的事物（如早期 AI 原生应用），无成熟参照系。
- 本地条件与参照市场结构性不同，映射必然失真。
- 政策/文化主导的领域，市场演化逻辑被非市场因素改写。

# 多元思维模型格栅与能力圈

芒格的两个核心工具：**格栅**（用多学科模型交叉看同一问题）与**能力圈**（知道自己知道什么）。
配套还有下重注检验与 lollapalooza 的方向判定。

> 阅读本文件后，回答中**必须出现**：①用了哪几个学科的模型交叉验证 ②能力圈四问中哪一问触发了边界。

---

## 一、格栅最小集

芒格自述：**80 或 90 个重要模型可承载约 90% 的分量**。起步只需 15 个。

| 学科 | 模型 | 一句话作用 |
| --- | --- | --- |
| 数学 | 概率与期望值 | 把"可能"折算成"值多少" |
| 数学 | 复利 | 时间与利率的乘积效应 |
| 数学 | 排列组合 | 路径数随规模指数增长 |
| 物理 | 临界点与相变 | 量的积累到某点会改变性质 |
| 物理 | 守恒律 | 转移成本必由某方承担 |
| 生物学 | 生态位 | 你不能占据两个位 |
| 生物学 | 演化与适应度 | 长期存续者不是最强的，是最适应的 |
| 心理学 | 认知偏误 | 见 twenty-five-biases.md |
| 心理学 | 激励结构 | 行为是激励的镜像 |
| 心理学 | 认知负荷 | 意志力有限，别靠硬撑 |
| 经济学 | 机会成本 | 真实成本是放弃的最好选项 |
| 经济学 | 规模经济与网络效应 | 优势随规模自我强化 |
| 经济学 | 边际分析 | 看增量，不看总量 |
| 工程学 | 冗余与容错 | 关键系统需要备份，不是简洁 |
| 工程学 | 反馈回路 | 见 systems-thinking |

**用法**：同一问题**至少用 3 个不同学科的模型**看一遍。三科结论一致 → 置信度高；
三科打架 → 冲突本身就是最有价值的信息。

## 二、能力圈四问

1. 我能**准确说出**这个领域的核心机制吗（不是只知术语）？
2. 我能说出这个领域**最常见的重大错误**是什么吗？
3. 我知道这个领域的**边界**在哪里（什么情况下我的判断会失效）？
4. 如果我错了，**我能承受**这个后果吗？

**四问答不上任何一问 → 出圈了。**

### 出圈信号（出现即停手）

- 只能用类比解释，无法说出机制
- 关键变量的数量级说不出来
- 找不到这个领域公认的重大失败案例
- 别人指出的反驳，自己想不出如何验证
- 结论的关键假设自己从没检查过

### 出圈时怎么办（三个选项）

1. **请圈内人**：具体问"如果只能问一个问题，问什么"——问题越具体越好
2. **降低赌注**：不确定性大时不做不可逆的决定，先做小成本试探
3. **改用代理问题**：找一个自己能判断的相邻问题，用它做近似

## 三、下重注检验

### 20 格考勤卡

> 巴菲特的方法：把一生中少数几次重大投资机会看作一张只有 20 格的卡片。
> 用法由芒格转述（源出 1994 年南加州大学毕业演讲，芒格说"巴菲特喜欢在商学院讲这个"）。

**检验问题**：

- 这件事在 20 格的范围之内吗？（一年做 20 次同等级决定 = 没在格内，是普通机会）
- 如果一辈子只有 20 次这样的机会，我会把它花在**这件事**上吗？
- 赔率与仓位匹配吗？

### 赔率—仓位对照

| 赔率（胜率×收益 ÷ 败率×损失） | 合理仓位 |
| --- | --- |
| < 1.1 | 不下注，或极小试探 |
| 1.1 ~ 2 | 小仓位 |
| 2 ~ 5 | 中等仓位 |
| > 5 且在自己能力圈内 | 可重注 |

**前提**：赔率高不等于该下注。若胜负不由自己控制（结果随机），高赔率也无意义。

## 四、Lollapalooza 的方向判定

多个倾向同向叠加时，结果**非线性**放大。方向决定性质：

### 同向叠加 → 放大机会

多个利好同时成立：某同行连续成功（社会认同）+ 自己也有专长（能力圈内）+ 赔率高（期望值正）
→ 值得重注，但**必须重读出圈信号**——此时判断力被叠加放大，出错也会被放大。

### 反向叠加 → 放大灾难

多个不利同时成立：社交压力要我跟进（社会认同）+ 沉没成本要我继续（剥夺超级反应）+ 从众氛围（社会认同二次作用）
→ **立刻停止**。这是最危险的组合，因为每一条单独看都不致命。

### 判定用法

数一数：此刻有多少个倾向在同时推我？
- **1~2 个**：正常，按常规判断处理
- **3 个以上同向**：主动放慢，考虑是否该减仓
- **3 个以上反向**：立即停止行动，改为收集信息

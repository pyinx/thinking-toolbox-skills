# 宏观思维

## 核心思想

- **不谋全局者，不足谋一域**：局部的最优解叠加起来，往往是全局的灾难。先看棋盘，再落子。
- **PEST 扫描**：政治/政策（P）、经济（E）、社会/人口（S）、技术（T）——任何决策都浸泡在这四股洋流里，顺之者昌逆之者亡。
- **宏观变量是硬约束**：利率、人口结构、政策方向、技术浪潮——个体再努力也拗不过宏观变量；聪明的做法是把它们当天气预报，而不是当敌人。
- **宏观叙事 ≠ 微观体感**：新闻里的宏观叙事（"经济下行""AI 颠覆"）与你的微观体感往往错位；决策要锚在可观测的微观数据上，用宏观理解方向而非制造焦虑。
- **自上而下 × 自下而上交叉**：自上而下看结构与趋势，自下而上看需求与事实；两者结论一致时才敢下重注，矛盾时以微观事实为准修正宏观判断。

## 分析步骤

1. PEST 扫描：这个问题受哪些政治/经济/社会/技术变量的影响？逐个列出。
2. 定方向：每个变量的走向是什么（上行/下行/拐点）？对我的问题是顺风还是逆风？
3. 识别硬约束：哪些宏观变量是不可改变的？我的方案是否建立在"改变它们"的幻想上？
4. 区分叙事与体感：当前流行的宏观叙事是什么？我掌握的微观一手事实支持它还是否定它？
5. 全局检验：我的局部最优解，放到全局棋盘上是助攻还是自伤？
6. 定位时间窗口：宏观变量给出的窗口期是打开还是关闭？还能维持多久？

## 关键问题清单

- 这件事最大的三个宏观变量是什么？它们在往哪走？
- 我是在顺应大势，还是在和大势拔河？
- 我的判断里，多少来自宏观叙事（新闻/情绪），多少来自微观事实（数据/一手经验）？
- 如果 PEST 各问一遍，哪个字母最可能杀死这件事？
- 这个决策在全局棋盘上，是在哪个更大的趋势里下注？
- 五年后回看，现在是不是某个宏观窗口的尾声？

## 输出要求

- 限长：默认模式 ≤300 字，全部模式 ≤150 字。
- 核心判断：一句话给出大势判断（顺/逆、窗口开/关）。
- 分析：PEST 扫描 → 硬约束 → 叙事与体感校准 → 全局检验。
- 行动含义：给出顺大势的布局建议、需要回避的逆风区、需盯住的宏观信号。

## 何时不适用

- 与大势无关的纯个人即时决策（中午吃什么）。
- 微观执行问题，宏观分析是逃避行动的借口。
- 宏观变量高度混沌、任何判断都是猜的极端不确定期（改用情景规划）。
- 与周期思维的分工：周期思维管**周期性摆动的位置与择时**（钟摆在哪儿、该攻该守）；本模型管**全局结构与长期大势**（PEST 走向、硬约束）；判据是「看结构性变化」还是「看周期位置」。
- 与时光机思维的分工：时光机思维管**跨市场的阶段映射**（成熟市场的昨天→本市场的今天）；本模型管**本市场的 PEST 变量扫描**（政策、人口、技术取向）；判据是「对标物已明确」还是「无明确对标物」。
- 与环境思维的分工：环境思维管**人所处的具体环境与场域**（圈子、城市、平台、信息食谱）；本模型管**宏观变量走向**（PEST、政策、人口、技术）；判据是「看你身边是谁」还是「看大趋势」。

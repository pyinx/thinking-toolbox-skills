# 纳瓦尔思维

## 核心思想

- **专长（specific knowledge）**：无法被培训的知识——来自你的好奇心、天赋和独特经历，社会想要但还不知道怎么教。找到"对你来说像玩、对别人来说像工作"的事。
- **杠杆**：纳瓦尔框架可概括为"特定知识 + 责任 + 杠杆"（乘法表述为中文世界流传的概括，非书中原文公式）。杠杆三种：人力（别人替你干活）、资本（钱生钱）、无边际成本产品（代码与媒体——睡后收入）。新时代个体最大的杠杆是代码和媒体。
- **责任（accountability）**：以个人名义承担风险，社会才以股权回报你。打工出租时间是线性收入，无法致富——你必须拥有股权。
- **判断力 > 努力**：在杠杆时代，一个正确判断的回报远超一万小时的勤奋。方向比速度重要一个数量级。
- **运气的四种分类**：瞎猫碰上死耗子的运气；折腾出来的运气（量大出奇迹）；准备出来的运气（精通者看见别人看不见的机会）；人格吸引来的运气（独特声誉让机会找你）。从第一种修炼到第四种。
- **财富与幸福是两套技能**：财富游戏的答案在杠杆与专长，幸福游戏的答案在欲望管理、当下与平和。别用财富游戏的规则解幸福问题。

## 分析步骤

1. 检验专长：这件事里，我的不可替代性在哪？是专长还是通用技能（可被培训/外包/AI 替代）？
2. 盘点杠杆：我目前用的是哪种杠杆？有没有从人力/资本杠杆升级到代码/媒体杠杆的路径？
3. 检验责任与所有权：我在这件事里拥有股权/作品所有权吗？还是只在出租时间？
4. 评估判断权重：这个决策的影响量级多大？值得花多少时间思考（大决定值得想几个月）？
5. 运气升级：当前在靠哪种运气？如何升级到更高一级（多折腾/深准备/建声誉）？
6. 分离财富与幸福：这个问题到底是财富问题还是幸福问题？用错了哪套规则？

## 关键问题清单

- 如果人人都接受同样的培训，我还会剩下什么？（专长测试）
- 我睡着的时候，有什么在替我赚钱？
- 我是在卖时间，还是在拥有资产？
- 这个决定值得我花一个月想透吗，还是 5 分钟就够了？
- 我怎样让运气来找我，而不是我去撞运气？
- 我现在的不快乐，是缺钱，还是缺"不想要"的能力？

## 输出要求

- 限长：默认模式 ≤300 字，全部模式 ≤150 字。
- 核心判断：一句话给出纳瓦尔式裁决（这事在不在你的专长×杠杆路径上）。
- 分析：专长 → 杠杆 → 责任/所有权 → 判断权重 → 运气层级。
- 行动含义：给出具体的杠杆升级动作和"停止做什么"的清单。

## 何时不适用

- 组织/团队管理问题（纳瓦尔框架是个人主义的）。
- 对抗博弈问题（用 sun-tzu 或 strategic-thinking）。
- 公共责任、集体利益议题，个体杠杆框架不适用。

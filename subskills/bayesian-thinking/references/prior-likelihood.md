# 先验、似然与后验

贝叶斯推理的完整操作流程。核心是**证据按其似然比修正先验**，而不是取平均或凭感觉。

> 阅读本文件后，回答中**必须出现**：①先验（基准率）是多少及其来源 ②这条证据的似然比强弱
> ③更新后的后验。只说"要结合实际情况"而不给数字，等于没读。

---

## 一、三步法

### 步骤 1：定先验（不看新证据）

先验 = **在没有任何这条特定证据时的基准概率**。

来源优先级：
1. **同类事件的实际发生率**（最好的先验）
2. 权威统计、行业报告的历史数据
3. 粗略的量级估计（"这类项目十个成一个"）

> 纪律：**先写先验，再看证据**。反过来就会被证据牵着走（这是"先看结论再找理由"的认知偏误）。

### 步骤 2：估似然比（看证据）

**似然比 = 证据在假设为真时出现的概率 ÷ 证据在假设为假时出现的概率**

| 似然比 | 强度 | 含义 |
| --- | --- | --- |
| > 10 | 强 | 几乎可以单独决定结论 |
| 3 ~ 10 | 中 | 显著改变信念 |
| 1 ~ 3 | 弱 | 略微移动 |
| = 1 | 无 | 该证据与假设无关，信念不动 |
| < 1 | 反向 | 削弱假设 |

**判读要点**：不是"这条证据听起来多有力"，而是"它在两种假设下出现的可能性差多少"。

- **高敏感度证据**：两种情况下都出现 → 似然比≈1 → 几乎没用
- **高特异度证据**：只在假设为真时出现 → 似然比高 → 决定性

### 步骤 3：更新后验

```
后验 ≈ 先验 × 似然比
```

精确计算用贝叶斯定理，实践中用乘法近似即可（偏差可接受）。

**关键**：多次更新时**先验用上一步的后验**，逐步累乘。

## 二、基准率校正（最常见的错误）

### 基准率谬误

忽略"这类事情通常怎样"，只看"眼前这条证据多有力"。

**典型场景**：
- 某种检测的准确率 99%，某项阳性 → 误以为患病概率 99%。
  实际：若患病率只有 0.1%（基准率），10000 人中 10 人患病，9900 人健康。
  检测阳性中约 9000 个是假阳性 → **实际患病概率约 1%**，不是 99%。

### 校正步骤

1. 查**基准率**（这类事件的实际频率）
2. 查**检测准确度**（灵敏度 = 真阳/全部阳性；特异度 = 真阴/全部阴性）
3. 用 2×2 表重算，不要用"准确率"直接当概率

**公式**（先验 1%、灵敏度 95%、特异度 95% 时）：

```
真患病者中检测阳性：1% × 95% = 0.95%
健康者中误报阳性：99% × 5% = 4.95%
后验 = 0.95 / (0.95 + 4.95) ≈ 16%
```

即阳性结果的真实概率只有 16%，而非 95%。

## 三、多证据组合

### 证据强度分级

| 等级 | 说明 | 权重 |
| --- | --- | --- |
| 系统性证据 | RCT、元分析、大样本统计 | 高 |
| 机制性证据 | 有明确因果机制的实验或观察 | 中高 |
| 专家共识 | 多位独立专家意见一致 | 中 |
| 个案证据 | 单个案例、亲历 | 低 |
| 传闻 | 道听途说 | 极低（应作为"假设"标注） |

**结论强度不得超过证据等级**。用传闻支撑的结论，只能是假设。

### 独立性检验（关键）

多个证据累乘时，必须问：**它们真的独立吗？**

- 三个报道同一件事 → 似然比不是乘三次，是乘一次
- "某大 V 说过"与"我朋友的朋友说" → 可能同源

**识别同源证据是贝叶斯推理最容易被忽略的步骤。**

### 停止规则

更新到某一步后再加新证据，后验变化 < 5 个百分点 → 停止收集，证据已耗尽。

## 四、期望值决策

决策时不止看概率，还要看收益：

```
EV = Σ(概率 × 结果)
```

**但期望值最大化不等于正确决策**——它是**多次重复决策**时的最优策略。
单次不可逆决策还要看**下行风险**（破产、声誉、关系断裂）：

| 期望值 | 下行风险 | 建议 |
| --- | --- | --- |
| 高 | 低 | 做 |
| 高 | 高（不可承受） | 做小额或分批；或买保险 |
| 低 | 低 | 不值得做 |
| 低 | 高 | 不做 |

## 五、常见错误清单

| 错误 | 表现 | 纠正 |
| --- | --- | --- |
| 先看证据再看先验 | 被证据牵着走 | 先写先验再看证据 |
| 忽略基准率 | 用准确率当概率 | 先查发生率 |
| 证据非独立却累乘 | 重复计算同一信息 | 问"这些证据同源吗" |
| 忽视非证据的缺失 | 没看到某证据不等于证据为负 | 缺失信息应下调而非上调后验 |
| 用平均代替更新 | 折中而非修正 | 乘法，不是加减 |

---

## 六、一句话流程

> **先写基准率 → 估似然比强度 → 验证独立性 → 乘法更新 → 重复直到信号耗尽 → 按期望值与下行风险决策。**
